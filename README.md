# 🎮 Three.js Game Dev Resource Catalog

A curated, searchable catalog of **104 resources** for building games with [Three.js](https://threejs.org/) — engines, physics, ECS/AI, rendering & effects, multiplayer/networking, UI, asset pipelines, audio, learning material, playable showcases, templates, and debug tools.

## 🌐 View it live

> **https://jawnzilla.github.io/threejs-game-resources/** — full catalog (111 resources)
> **https://jawnzilla.github.io/threejs-game-resources/assets.html** — 🖼️ Visual Asset Browser (thumbnails)
> **https://jawnzilla.github.io/threejs-game-resources/cheatsheet.html** — 📋 Agent Skills Cheat Sheet

Three pages, all generated from data files:

- **`index.html`** — the full searchable/filterable catalog of engines, libraries, tools, learning and showcases, with live GitHub ★ counts.
- **`assets.html`** — the **Visual Asset Browser**: a thumbnail grid of 30 curated sources for 3D models, textures, HDRIs, characters & animations, 2D/UI art, voxel tools, marketplaces and AI-generation tools. Filter by type and license (CC0 / Free / Freemium / Paid), search by keyword. Thumbnails are pulled from each site's og:image at build time (favicon fallback).
- **`cheatsheet.html`** — the **Agent Skills Cheat Sheet**: a decision table (what you want → which pack → which skill) plus 71 distilled skills across 6 open-source AI skill packs (scottstts graphics, MengTo's Vesper Fall set, Mint MCP, majidmanzarpour's game skills, img2threejs, GameBlocks), extracted from each repo's actual SKILL.md contents.

## 🗂️ Repo layout

```
catalog.json    # Full catalog: categories + resources (name, url, desc, tags, github repo)
assets.json     # Visual asset browser: sources + type/license + site for thumbnails
cheatsheet.json # Agent skills cheat sheet: decision table + distilled skill digests
build.py        # Fetches live GitHub star counts + renders index.html
build_assets.py # Fetches og:image thumbnails per site + renders assets.html
build_cheatsheet.py # Renders cheatsheet.html from cheatsheet.json
index.html      # Generated full catalog (served via GitHub Pages)
assets.html     # Generated visual asset browser (served via GitHub Pages)
cheatsheet.html # Generated agent skills cheat sheet (served via GitHub Pages)
stars.json      # Cached star counts (gitignored; regenerated by build.py)
thumbs.json     # Cached thumbnail URLs (gitignored; regenerated by build_assets.py)
```

## 🔄 How to update

1. Edit `catalog.json` (full catalog), `assets.json` (visual browser) or `cheatsheet.json` (cheat sheet).
2. Run `python build.py`, `python build_assets.py` and `python build_cheatsheet.py` (requires `gh` CLI authenticated for stars).
3. Commit and push — GitHub Pages picks it up automatically.
