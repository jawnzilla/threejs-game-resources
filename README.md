# 🎮 Three.js Game Dev Resource Catalog

A curated, searchable catalog of **104 resources** for building games with [Three.js](https://threejs.org/) — engines, physics, ECS/AI, rendering & effects, multiplayer/networking, UI, asset pipelines, audio, learning material, playable showcases, templates, and debug tools.

## 🌐 View it live

> **https://jawnzilla.github.io/threejs-game-resources/**

The live catalog is the single-file `index.html` — searchable, filterable by category, with GitHub ★ star counts fetched live at build time.

## 🗂️ Repo layout

```
catalog.json   # Source of truth: categories + resources (name, url, desc, tags, github repo)
build.py       # Fetches live GitHub star counts (gh api) + renders index.html
index.html     # Generated, self-contained, viewable catalog (also served via GitHub Pages)
stars.json     # Cached star counts (gitignored cache; regenerated by build.py)
```

## 🔄 How to update

1. Edit `catalog.json` (add/remove items, keep the schema).
2. Run `python build.py` (requires `gh` CLI authenticated).
3. Commit and push — GitHub Pages picks it up automatically.
